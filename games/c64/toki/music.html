Commodore 64 · 1991 · Ocean Software

Toki

The sound chip, two modes, and a driver with three sets of tunes.

Listen

Music: three tunes and ten sound effects

The player below runs the game's own sound driver on the kit's 6502 simulator, one call a frame, and plays what it writes to the SID.

Each button starts its sound the way SPACE switches the sound in the game $52E6: the driver silences the chip $6EB0, starts a tune set $66A9 or an effect $6633, and then runs once a frame $6787. The driver's bytes come from the Source tab, and every tune and effect was checked against the same calls made on the kit's 6502 simulator.8

The game's own routines start only the second set, Set 1, at the start of a round and when SPACE turns the music on $808B. No routine in the main code starts Sets 0 and 2; command 31 of the objects' scripts starts the music with whichever set its script names. Of the effects, effect 0 plays when Toki jumps $86A4 or lands and jumps again $8B98, and effect 9 ($24) when he is hit $8B78 $8E12 or the clock runs out $8295; with music on, the game fades the music out there instead. Effects 1 and 4 come from the routine that tests objects against Toki $A3BF, 5 from the start of an object's type handler $A88E, 6 from a check in the object slots $AD8D, and 7 and 8 from Toki's firing $AF34. No call in the code names effects 2 and 3 directly.

The table of effects has a bug. $6633 starts an effect's voices from four list entries beginning at its number, and before each voice starts it should silence that voice's control register. It looks the register up with the list position instead of the voice number $6659, so only effect 0 finds the right one. For the others it reads past the end of the three-entry table of voice offsets, and the zero lands in another register: effect 3's third voice, for example, writes $D4AD, which the chip reads as $D40D, voice 2's sustain and release.

Sound

Sound effects or music, never both

Sound effects or music, never both: one flag decides, and a press of SPACE flips it.

The choice is one flag $00DF. With music on, the game silences the sound chip and starts the music driver; with sound effects on, it clears the queue and starts the effects $5290. A request for a sound effect is ignored while music is on, and up to three can wait in the queue $0B8C. Each frame the game plays whatever is queued and then runs the driver $0BE2.

The driver

Three voices, each with its own small programs

The driver gives each of the SID chip's three voices a script and several tables that change it over time.

Each voice has its own script, which says what to play and for how long $6A09. Beside it, a program for the pulse width sweeps the sound's tone $6CBE, a pitch program slides the frequency $6D08, and an arpeggio steps through note offsets $6D81. One filter program, shared by the three voices, moves the filter cutoff $6DCE. The master volume can fade down or up, at a rate set by the game or by a script command $6ED8.

The effects are separate from the music. Ten sound effects each start from a group of four entries in a list $7C15, and ten short one-shot waveforms hold their steps $6FC2.

Tunes

Three sets of scripts, and the callers use one

The driver can start three sets of three voice scripts, and the game's own routines name the second.

A table holds three sets of start addresses, one address for each voice $70BA. The two places in the main code that start the music, at the start of a round and on SPACE, both pass 6, which picks the second set $808B. Switching music on with SPACE loads that set's three start addresses into the driver, and a second press switches it off again.7 A third caller is command 31 of the objects' scripts, which starts the music with the set named by the byte after the command, and only while music is on $B33C. Which scripts use that command, and which set they name, has not been traced. Retro Gamer says the C64 version dropped one of the arcade's music tracks.3
